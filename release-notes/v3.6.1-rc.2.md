# ATO Assistant 3.6.1-rc.2

本次预发布改进 AIBP 连招结算、多语言显示与卡图加载，并修复资料包在 Asset Studio、Android 和 Docker 中的兼容性。公告省略后续循环的角色与具体战斗内容。

## 更新

- 具有连招机制的 Boss 抽取 AI 后进入待结算区，关闭大卡不会弃牌。大卡右侧提供「打断连招」和「继续连招」；结算后弃置当前 AI 并向下推移连招轨道。继续连招只额外抽取一张 AI，第二张不会再次触发连招。
- AI 大卡显示当前能打断连招的武器类型；达到不可打断条件时明确提示，并禁用打断按钮。连招状态与卡牌结算支持刷新恢复和撤销。
- 民间翻译同时显示英文名称；官方中文使用官方术语，English 显示英文。修复连招状态、大迷宫、版图提示及部分动态控件的中文残留和长英文按钮遮挡。
- 优化首屏面板、随命卡和标志卡加载，使用预览图显示小卡，放大时保留原图。AIBP 使用最长边 1024 像素的版图预览，第二屏继续使用高清原图。
- 决战版图改为统一目录 `ss/battle-board/`，原图和预览分别为 `battle-board.jpg`、`battle-board.jpg.preview.jpg`。资料包生成关联预览，Android 导入兼容旧版图路径。
- 修复 Asset Studio 将 `.bin` 素材当图片解码、安装时遗漏预览图，以及民间包仅带官方正文时误要求原书扫描图的问题。图片和二进制素材均校验哈希；已批准的原图覆盖会同步更新预览，未批准覆盖的内容保留。
- 更新 Docker Compose v2/v1 挂载和安装脚本，迁移旧路径版图时保留旧文件。程序打包排除本地 `outputs/` 验证数据。

## 升级必读：Docker 与 atopack

**Docker 用户必须同时更新 compose 和镜像。只执行 pull、继续使用旧 compose，会缺少新的版图目录挂载。**

1. 备份安装目录中的 `data/`、`app/` 和自定义 compose/.env 配置。
2. 从本次标签下载与镜像匹配的 [compose.yaml](https://github.com/banard2049-cpu/ATO_assistant/blob/v3.6.1-rc.2/tools/packaging/docker/compose.yaml)；旧版 `docker-compose` 用户下载 [compose.legacy.yaml](https://github.com/banard2049-cpu/ATO_assistant/blob/v3.6.1-rc.2/tools/packaging/docker/compose.legacy.yaml)。将文件放到安装目录，并保留自己的端口和部署设置。
3. 确认包含 `./app/ss/battle-board:/app/ss/battle-board` 目录挂载，在 `.env` 中设置 `ATO_VERSION=3.6.1-rc.2`。使用自定义 `ATO_IMAGE` 的用户也要更新到对应镜像；预发布不更新 `latest`。
4. Compose v2 执行 `docker compose pull && docker compose up -d`；v1 执行 `docker-compose -f compose.legacy.yaml pull && docker-compose -f compose.legacy.yaml up -d`。自建镜像用户重新构建并重建容器。

**请更新并重新导入 2026-10-11 重新生成的新版 atopack（民间版/官方版，q85），不要只更新程序。** 新包包含新的版图路径和卡牌预览；旧包可能缺少这些素材。

- Android：先安装本次新版 APK，再在应用中导入新版 atopack。
- Asset Studio：先更新到本次版本的源码，再导入并安装新版 atopack；旧版导入器不支持本次二进制素材和预览安装修复。
- Docker/NAS：将新版 atopack 解压后的资源复制到安装目录的 `app/` 下；版图原图和预览应落在 `app/ss/battle-board/`，然后刷新页面。
- Portable：更新程序后，将新版 atopack 解压到程序根目录，保留存档目录。

`.atopack` 只更新资源，无法更新连招按钮或导入器代码。程序包和公开仓库不包含游戏素材；新版资料包由使用者自行准备，不附在公开 Release 中。
