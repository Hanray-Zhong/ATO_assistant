# ATO Assistant 3.6.1-rc.1

本次预发布改进 AIBP 的名称显示与部分特殊 Boss 的大卡显示。公告省略后续循环的角色与具体战斗内容。

## 更新

- AIBP 的 Boss 标题、侧栏、搜索结果和 Trait、Token 弹窗名称随民间翻译、官方中文或 English 切换。主控台的选择即时同步到已打开的 AIBP 页面，刷新后保留。
- Boss 搜索兼容三种显示名称与原有别名，英文搜索支持正确拼写的名称。
- 部分特殊 Boss 的正面面板不再随等级切换为背面；背面大卡作为默认不显示的可选 TR O 特性卡，在 Trait 选择中勾选后加入特性区。
- 修正这类背面大卡的缩略图方向、排列和放大方向，保留等级数值与特性调整。

## 下载

- Android：`ATO-Assistant-3.6.1-rc.1.apk`。
- Windows：`ATO-Assistant-Portable-3.6.1-rc.1-windows-x64.zip`。
- macOS：`ATO-Assistant-Portable-3.6.1-rc.1-macos-arm64.zip` 与 `ATO-Assistant-Portable-3.6.1-rc.1-macos-x64.zip`。
- Docker：`ghcr.io/banard2049-cpu/ato_assistant:3.6.1-rc.1`；预发布不更新 `latest`。

程序包不包含游戏素材。现有资料包与存档可继续使用。安装包和镜像由 GitHub Actions 构建，完成后发布到本次预发布页面及镜像仓库。
