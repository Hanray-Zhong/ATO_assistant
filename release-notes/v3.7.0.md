# ATO Assistant 3.7.0 · 重大更新

本次是探索卡结算系统的重大更新：从逐项人工记账改为「一键处理可自动部分、选择后结算、手动效果保留待办」，同时改进战斗视线、第二屏同步和探索界面。更新公告仅说明功能，不展开后续循环的剧情和具体卡牌内容。

## 更新

### 重大更新：探索卡结算

- 「一键结算」会读取最新记录表，处理本次抽牌中已支持的资源、数值和条件分支。单卡使用绿色「自动结算」按钮；抽牌和刷新不会直接发放收益。
- 外交关系从记录表自动读取。外交菜单只执行当前关系对应的一行，支持多种已存在的阵营字段拼写；关系未填写时保留待办。有多个适用本地阵营时才需要选择。
- 补齐卡面图标到记录表字段的对应关系，包括命运、船体、船员、难民、猜忌、悖论、债务、知识和宁芙召唤充能等。难民使用独立计数，不再当作变节者；船体不再被混记为泰坦。
- 自动获得泰坦时叠加现有梦行者数量；失去泰坦时优先扣梦行者。仍有多个可损失对象时保留选择入口。
- 商人支持选择兑换方案、次数和外交奖励资源。兑换两边显示当前库存，结算检查完整成本并扣增资源，保留本卡兑换次数限制和撤销。
- 资源代缴只提供库存足够的选项；全部库存不足时按对应替代规则处理。资源与附带数值同次保存，库存或条件变化后会重新检查，避免部分扣款。
- 接入更多复合数值规则，包括难民、猜忌、债务门槛，最后一名船员的损失例外、轮回长度变化，以及神浆按库存分档结算。**神浆减半后的剩余库存向上取整。**
- 可选收益、二选一和资源分支在选择后处理。地图派系可自动用于数值判断；达到剧情事件门槛时先留下事件待办，标记事件完成后再处理后续奖励。
- 持续标记和延迟效果支持登记、到期处理及撤销。科技临时禁用会在科技页和第二屏显示修复时间；实际战斗、剧情阅读、装备卡池和地图操作仍保留对应待办。
- 防止重复点击、丢失保存响应和刷新造成重复结算。撤销按实际增减量回退，保留后来独立修改的库存；撤销前序效果时同步撤销依赖它的后续效果并清除相关完成标记。

## 重要规则：进展与灾祸需要手动放置

**探索卡获得的进展和灾祸不会自动加入某条轨道，因为玩家需要选择放置位置。**

- App 仍会判断适用条件和数量，并显示「请手动选择放置位置并放置」的黄色待办。
- 同卡其他已支持效果继续自动处理；放置完毕后再标记完成。选择灾祸收益的分支也仍需手动放置。
- 带「下次定时战斗前一次」限制的进展收益，在手动放置后登记限制；知识收益仍按已支持规则结算。
- 旧版已写入的进展、灾祸结算保留并可撤销，不会自动回退或再次要求领取同一份收益。

## 界面与战斗改进

- 横向探索卡仅在抽出后的待结算区域横向展示；侧置商人卡会转正。手机宽度下自动缩放，卡库与暂时移出区域保留原有展示方式。
- 保留各循环的探索卡组、卡库选择和暂时移出入口；优化折叠区、派系标签、提醒配色及按钮布局。
- 改进英文动态提示，并区分绿色自动处理、黄色手动待办和撤销入口。
- 战斗视线面板按 Boss 当前等级读取移速，并把同一移速同步到第二屏；支持无穷移速的快照编码。
- 攻击距离加入减／加步进按钮，改善工具栏布局；主控台与第二屏使用一致的视线、射程和路径计算。
- 延长对应循环的日期轨道，超出原末尾后仍可继续推进并显示当天战斗提醒。

## 升级与旧存档

- 更新程序后刷新页面，保留现有战役与记录表存档。使用旧页面的浏览器窗口也需要刷新。
- 当前抽牌若带旧版图标错误或部分结算记录，App 会提示先撤销旧分项或手动补齐，再执行新规则。更早历史记录中的错误变节者等计数不会自动搬移，请按原卡核对。
- 单纯 N 选 1 属于选择后结算流程；涉及实际放置、牌堆抽取、剧情或地图操作的剩余效果仍会明确列出。

安装包和镜像由 GitHub Actions 构建。公开程序包不附带游戏卡图、规则书、战役存档或 atopack；继续使用已安装的合法资源。
